# Company Service — сервис компаний и вакансий

## Основные сценарии

- Создание компании
- Создание черновика вакансии
- Публикация вакансии
- Архивация вакансии
- Добавление в команду компании новых hr-специалистов, роли: админ, recruiter
- Просмотр компаний кандидатами
- Поиск и просмотр вакансий кандидатами по ключевым словам и фильтрам

## Инфраструктура

- PostgreSQL - основная бд, источник истины
- Apache Kafka - публикация и консюминг событий
- Redis - кеширование
- ElasticSearch - полнотекстовый поиск

## Поиск вакансий

- Учитывается название вакансии, название компании, описание вакансии
- Подбор вакансий идет по релевантности поиска (название вакансии > название компании > описание)
- При добавлении / изменении вакансий индексация в elastic идет асинхронно, через Kafka

## Кеширование

- используется паттерн cache-aside
- time to live
